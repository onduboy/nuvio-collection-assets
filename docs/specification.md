# Nuvio Collection Assets Specification

## Purpose

This repository provides a curated collection of visual assets designed for Nuvio collections.

Its goal is to maintain a consistent visual language across all community-created collections.

---

## Collection Structure

Each collection is stored in its own directory.

Example:

collections/
└── services/
    └── netflix/
        cover.webp

### Asset Naming

The primary artwork for every collection must be named:

cover.webp

This naming convention is used throughout the repository to provide a predictable and consistent structure.

---

## Image Format

- Format: WebP
- Aspect ratio: 16:9
- Resolution: 1280 × 720 px

---

## Naming Convention

All folders use **kebab-case**.

Examples:

- netflix
- disney-plus
- apple-tv
- prime-video
