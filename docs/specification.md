# Nuvio Collection Assets Specification

## Purpose

This repository provides a curated collection of visual assets designed for Nuvio collections.

Its goal is to maintain a consistent visual language across all community-created collections.

---

## Asset Structure

Every collection follows the same directory structure.

Example:

collections/
└── services/
    └── netflix/
        ├── backdrop.webp
        ├── preview.webp
        └── manifest.json

---

## Image Format

- Format: WebP
- Aspect ratio: 16:9
- Resolution: 1280 × 720 px

---

## Naming Convention

All folders use **kebab-case**.

Examples:

- netflix
- disney-plus
- apple-tv
- prime-video
