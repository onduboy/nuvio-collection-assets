# Nuvio Canvas

Artwork designed for Nuvio media collections.

This repository contains a curated collection of original backdrops, collection artwork, templates and graphic resources created to provide a clean and consistent interface for Nuvio.

---

## Goals

- Minimalistic visual style
- Consistent design language
- High-resolution assets
- Community-friendly organization
- Easy integration with Nuvio collections

---

## Design Principles

The objective of this repository is to maintain a cohesive visual language inspired by modern streaming platforms.

Each collection should prioritize:

- Clean composition
- Balanced typography
- Limited color palette
- Consistent spacing
- High readability
