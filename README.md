# Nuvio Canvas

A curated collection of visual assets for Nuvio Collections.

This repository contains custom artwork designed to replace the default collection images generated by community metadata sources.

---

## Why this project?

This started as a personal project.

After setting up Nuvio using the Perfect Setup guide, I wanted a cleaner and more consistent visual style for my collections. Rather than simply replacing the images locally, I decided to build a public repository that could also help other Nuvio users looking for an alternative visual style.

At the same time, I wanted to use this project as an opportunity to learn Git and GitHub before moving on to larger software and open-source projects.

Every commit represents part of that learning process.

---

## Acknowledgements

This project was inspired by the default collection setup described in the Nuvio Perfect Setup guide.

The goal of this repository is not to replace that work, but to provide an alternative set of visual assets for users who prefer a different design style.

## Goals

- Create clean, minimalist collection artwork.
- Maintain a consistent visual language.
- Keep the repository simple and easy to use.
- Document the workflow as the project evolves.
- Learn Git and GitHub through a real-world project.
